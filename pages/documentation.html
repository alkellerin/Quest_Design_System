Project Summary

Welcome to the Quest Design System which defines the visual design for online assets for the Indiana Public Retirement System.

Product Goals

Goal #1

Create a consistent visual language for all current and future web products.

Goal #2

Speed both design and development of products, allowing a small team to work efficiently and deliver value.
