Quest Design System uses Phosphor iconography styles. Normally, icons will be under the css style "ph". When hovered, the css style should be "ph-fill"

See All Phosphor Icons

Icon Sizing

Icons should be increased in 4px/.25rem ranging from 12px to 24px. To change the original size of an icon, use the icon's style class and add the size in px. For example, if I want to change the size of

ph-arrow-circle-right

, I would add another style class called

icon24

at the end. In total the code snippet should look like

ph ph-arrow-circle-right icon24
